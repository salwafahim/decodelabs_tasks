# Iris Flower Classification Using SVM

This project was developed in Google Colab as part of my Artificial Intelligence Internship at DecodeLabs.

## Overview

An Iris Flower Classification model was developed using Support Vector Machine (SVM) to classify Iris flowers into different species based on their sepal and petal measurements.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- SVM

## Methodology

- Dataset exploration and preprocessing
- 70/30 train-test split
- Feature scaling using StandardScaler
- SVM with RBF kernel
- Model evaluation using accuracy, classification report, and confusion matrix
